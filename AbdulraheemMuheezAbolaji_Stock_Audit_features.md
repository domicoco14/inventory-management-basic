# Stock Audit Features

## 1. Blind Counting and Recount

### Short Explanation
Blind counting means counters do not see the quantity recorded in the system while counting the physical stock. If there is a big difference between the physical count and the system quantity, the items are counted again.

### Relevance to an Inventory Management System
It helps improve the accuracy of inventory records by reducing counting errors and preventing the system quantity from influencing the physical count. It also helps identify missing or incorrectly recorded items.
